ABOUT THIS WORKSPACE

Explore texts across time.

Stylometry Tool is an interactive research website for comparing Arabic poetry from different historical periods with the Quran. Comparisons use the historical folded spelling of the corpus. Feature frequencies, hierarchical clustering (HC), and principal component analysis (PCA) offer complementary views of the selected texts.

The available poetry groups are Pre-Islamic, Transitional poets (Mukhadramun), Umayyad, Abbasid, Andalusian, Fatimid, Ayyubid, Mamluk, Ottoman, and Modern. Choose which eras to include, the number of samples, and the length of each sample. Quran, Pre-Islamic poetry, and Modern poetry are selected by default; you can also compare poetry groups with one another.

The default is 10 samples from each selected group, with 7,000 words per sample, including the Quran. Longer passages and more examples provide a broader basis for estimating feature frequencies and can make recurring patterns clearer. Samples are drawn from non-overlapping passages; groups with less text supply fewer complete samples.

Use the Feature Set dropdown to represent the samples as most frequent words, word bigrams, or character sequences of 1, 2, 3, 5, or 7 characters. Explore their similarities in the Cluster tree and their distribution in the PCA map (principal component analysis). Changing the groups, sampling settings, or feature set automatically updates the results, so you can see how each choice affects the patterns.
